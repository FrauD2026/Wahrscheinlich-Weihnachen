# Weihnachtliche Wiederholung: Wahrscheinlichkeitsrechnung

Interaktive Wiederholung für Mathematik Klasse 12 (Weihnachtsferien 2026/27).

- Etappe 1: Baumdiagramme, Pfadregeln, Gegenereignis, Erwartungswert
- Etappe 2: Vierfeldertafel, bedingte Wahrscheinlichkeit, Unabhängigkeit
- Etappe 3: Bernoulli-Ketten und Binomialverteilung (TI-84 Plus)

14 Aufgaben mit Prüffunktion, Tipps und Lösungen. ★ = Basis für alle, ★★ = Abiturniveau.
Jede gelöste Aufgabe schenkt einen Buchstaben des Lösungsworts.

## Veröffentlichen mit GitHub Pages

1. `index.html` (und diese README) in ein Repository hochladen.
2. Unter **Settings → Pages** als Quelle den Branch `main` und den Ordner `/ (root)` wählen.
3. Nach ein bis zwei Minuten ist die Seite unter `https://<benutzername>.github.io/<repository>/` erreichbar.

Die Seite besteht aus einer einzigen Datei. Formeln werden über MathJax (cdnjs) und die Schrift über Google Fonts geladen, dafür ist eine Internetverbindung nötig. Der Lernfortschritt wird nur lokal im Browser gespeichert.
